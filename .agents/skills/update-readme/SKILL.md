# Update README

1. Lee el archivo `README.md` actual en la raíz del proyecto para entender su estructura.
2. Utiliza la herramienta `git diff HEAD~1` (o revisa el historial de chat reciente si tienes el contexto) para ver qué archivos se modificaron y qué cambios lógicos se introdujeron.
3. Redacta una nueva sección o modifica las existentes en el `README.md` resumiendo las nuevas características, endpoints o configuraciones agregadas.
4. Aplica los cambios usando la herramienta de edición o sobreescritura de archivos. No repitas el documento entero en el chat, solo aplica el cambio.
